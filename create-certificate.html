Two Ways to Create & Manage Origin CA Certificates

The dashboard UI is still fully available. Only the legacy Origin CA Service Key was removed — not the certificate interface. You have two distinct ways to manage your origin certificates.

💡 Clarification: UI vs. Authentication Credential

No — the dashboard UI is still fully available. The official deprecation on September 30, 2026 applied strictly to the legacy Origin CA API Key (Service Key) authentication credential (X-Auth-User-Service-Key). The certificate management interface, the Origin CA service itself, and automated API management remain completely operational.

Option 1 Always Available

🖱️ Dashboard UI (Manual / Click-through)

Ideal for manual setups, single servers, quick testing, or when you prefer a browser interface without scripting.

Where to find it:

Navigate to SSL/TLS → Origin Server → Origin Certificates tab.

What you can do:

  • Create a certificate:
    • Let Cloudflare generate the private key + CSR automatically, or
    • Paste your own pre-generated CSR (private key never leaves your server).
  • List existing certificates: View expiration dates, associated hostnames, and status.
  • Revoke a certificate: Instant 1-click revocation from the table.

💻 Automation Quick Reference (Option 2)

Here is how to execute all four operations with curl using your scoped API Token:

1. Create an Origin Certificate

curl -s -X POST https://api.cloudflare.com/client/v4/certificates \
  -H "Authorization: Bearer $CF_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "hostnames": ["example.com", "*.example.com"],
    "requested_validity": 5475,
    "request_type": "origin-rsa",
    "csr": "-----BEGIN CERTIFICATE REQUEST-----\n..."
  }'

2. List Existing Certificates

curl -s -X GET "https://api.cloudflare.com/client/v4/certificates?zone_id=$CF_ZONE_ID" \
  -H "Authorization: Bearer $CF_API_TOKEN"

3. Get Details of a Specific Certificate

curl -s -X GET "https://api.cloudflare.com/client/v4/certificates/$CERT_ID" \
  -H "Authorization: Bearer $CF_API_TOKEN"

4. Revoke a Certificate

curl -s -X DELETE "https://api.cloudflare.com/client/v4/certificates/$CERT_ID" \
  -H "Authorization: Bearer $CF_API_TOKEN"

⚖️ Side-by-Side Comparison

Aspect Option 1: Dashboard UI Option 2: API (Token)
Primary Use Case Single origins, manual setup, visual inspection CI/CD pipelines, Kubernetes, cert-manager, scripts
Prerequisites Cloudflare Dashboard login API Token (Zone > SSL and Certificates > Edit)
CSR Generation Can generate both private key + CSR in browser, or accept your CSR Accepts your pre-generated CSR via JSON payload
Validity Options 7 days to 15 years (default 15 years) 7, 30, 90, 365, 730, 1095, or 5475 days
Status Today Fully Operational Fully Operational (using Bearer API Token)
✨ Takeaway: Choose Option 1 when you want instant visual setup in your browser. Choose Option 2 when you need repeatable, infrastructure-as-code automation.
